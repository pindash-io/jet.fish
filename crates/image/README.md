# jetfish_image

<!-- cargo-rdme start -->

VT image protocols: kitty graphics (`DCS q` / `APC _G`), DEC Sixel, and
iTerm2 inline images (`OSC 1337;File=…`). Parsing/decoding only — the host
owns rasterization + placement.
